1

Profile the machine

Decode reads every weight once per token, so bytes are speed — but kernel format beats file size. On this iGPU, a smaller Q4_0 file was 18–25% slower. Profile first.

2

Calibrate on the job

An importance matrix over mixed prose + code. A code-only matrix improved perplexity and broke arithmetic — so we measure tasks, not just one scalar.

3

Measure, then publish

Quality first, speed last. Cooled, interleaved runs, a control model, raw eval files and a SHA256 manifest shipped with the weights. The method transfers; the numbers do not.

What we are not.

Not a frontier lab
We do not train giant models or race the big labs. Small, local and useful is the point.
Not a cloud provider
Working without the cloud is the whole idea, not a paid tier.
